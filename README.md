# Spot Material – test pages

Prototype search for the RED&Pro materials database.
Live at https://spotmaterial.github.io/material-intelligence/

- `index.html` / `search.html` – search (start here)
- `material.html?code=…` – material grade or family
- `innovation.html?code=…` – innovation

The pages read published records from the Supabase project "Spot Material" using its publishable key,
which only allows the read-only search and page functions. Company, availability and rating figures
for innovations are drafts under review.

To update: replace the html files here with the newer versions from `claude 1` (and copy search.html to index.html too).
