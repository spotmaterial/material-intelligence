API

The database can be read over HTTPS with a public, read-only key. Every call is a POST with a JSON body and returns JSON. The same calls drive this website.

Base URL and key

Base URL:  https://bjkkqawalpuvsubnbodt.supabase.co/rest/v1/rpc/
Key:       sb_publishable_ZZN2JFwNHFbBLLjh2DE3cg_4t1YvQ7m

Send the key in both the apikey and Authorization: Bearer headers. The key can only run the read-only functions listed below.

Limits

Calls are rate-limited per connection. Normal research use stays well inside the limits; if you need larger volumes, get in touch rather than scraping. A request over the limit returns HTTP 429; wait and try again.

Notes on the data

  • Codes: families end in -0000 (e.g. BA-0000), grades share the family prefix, innovations start with INN-.
  • Values are given as the original text (raw) and as numbers (min, max or typical). Some units are still marked "unit_status": "proposed".
  • Ratings: levels 1–5 from banded thresholds; better says whether lower or higher is better; source is own or family (taken from the family when the grade has no value).
  • Rules & certifications are what to check for a material, not compliance statements.
  • Innovations are not rated on the relative scales.
